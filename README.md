#  Objective

The objective of this assignment is to perform end-to-end analysis on a dataset, involving:

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Visualizations using libraries like `matplotlib`, `seaborn`, and `plotly`
- Statistical summary and insights

# Getting Started

# Prerequisites

Make sure you have the following installed:

- Python 3.x
- Jupyter Notebook or JupyterLab

# Required Libraries

You can install the required packages using:

```bash
pip install pandas numpy matplotlib seaborn plotly
```

### Run the Notebook

Open the notebook with Jupyter:

```bash
jupyter notebook Assignment_Wb.ipynb
```
